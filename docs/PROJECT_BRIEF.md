# TaskMind AI - Project Brief

## Executive Summary

Sistema de gestión de tareas empresariales con motor de IA para priorización inteligente, análisis de contexto y sugerencias automáticas.

## Problem Statement

Los equipos pierden 40% del tiempo decidiendo qué tarea hacer siguiente. TaskMind automatiza esta decisión usando NLP.

## Target Audience

- Zebra Ventures (demostración técnica)
- Equipos de desarrollo ágiles
- Product managers

## Core Value Proposition

"De 100 tareas sin priorizar a un roadmap claro en 3 segundos con IA"

## Success Metrics

- Impresionar en entrevista técnica ✅
- Demostrar arquitectura limpia ✅
- Mostrar IA aplicada real ✅
- Código production-ready ✅

## Technical Constraints

- Tiempo: 1 weekend (16-20h)
- Costo: $0 (todo open source)
- Stack: Python/Django obligatorio
- Deployment: Local + Docker
